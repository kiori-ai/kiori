# Security

Please report security problems privately, to [help@kiori.io](mailto:help@kiori.io) with "Security" in the subject, not in a public issue.

Tell us what you found, how to reproduce it and what it affects. We'll reply as soon as we can, usually within a few days, keep you posted while we fix it, and credit you when the fix is out, if you'd like.

**In scope:** the code in this repository (the server, the console, the SDKs and the SillyTavern extension) and the hosted service at kiori.io and api.kiori.io.

**Please don't** access or change other people's data, run load or denial-of-service tests, or try social engineering. Test on a Kiori of your own, or on your own project on api.kiori.io.

[docs/security.md](docs/security.md) explains what Kiori stores, what it doesn't, and how keys are protected.
